# 크레이지 아케이드 (모바일 브라우저판)

PC판 마지막 패치(00967, 2026-06-10)의 에셋으로 만든 크레이지 아케이드. 가로 화면에 PC판 800×600 화면을 그대로 두고,
양옆 빈 곳에 모바일판(크아M)처럼 조이스틱과 물풍선 버튼을 둡니다.

## 하는 법

1. 처음 화면(PC판 로그인 화면)의 **아이디** 칸에 닉네임을 쓰고
   - **1P**: 혼자놀기 (컴퓨터와 대전, 대기방에서 컴퓨터를 더 넣을 수 있음)
   - **확인 / 2P**: 온라인 로비
2. 로비: **방만들기**, **바로시작**(빈자리 있는 방에 들어감), 방 목록에서 골라 들어가기, 방 번호(4자리)로 입장.
   공유 링크 `…/crazyarcade/?room=1234`도 됩니다.
3. 대기방: 캐릭터, 팀 색, (방장) 맵·팀전/개인전을 고르고 **준비** → 방장이 **시작**.
   - **팀전**: 같은 팀 색끼리 한 편. 1:1, 2:2, 3:3, 4:4, 2:2:2:2 … 팀이 둘 이상이면 시작됩니다.
   - **개인전**: 모두가 적.
   - 방장은 빈자리를 눌러 컴퓨터를 넣고, 아래 "닫기"로 자리를 닫습니다.

## 조작

| PC | 휴대폰 | 동작 |
|---|---|---|
| 방향키 / WASD | 왼쪽 조이스틱 | 이동 (모서리에 걸리면 알아서 미끄러져 돎) |
| Space | 오른쪽 큰 물풍선 버튼 | 물풍선 놓기 |
| Ctrl / Z | 바늘 버튼 | 바늘: 물방울에 갇혔을 때 탈출 |
| X | 방패 버튼 | 방패: 3초 동안 물줄기 막기 |

## 규칙 (PC판과 같게)

- 물풍선은 2.8초 뒤 터지고, 물줄기에 닿은 물풍선은 함께 터집니다. 물줄기는 부서지는 블록에서 멈추고 블록을 깹니다.
- 물줄기에 맞으면 물방울에 갇힙니다(약 4초). 같은 팀이 닿으면 구출, 상대가 닿으면 터짐, 시간이 지나도 터짐.
- 아이템: 물풍선(+1), 물약(+1), 최대 물줄기, 스케이트(+1), 빨간 악마(속도 최대), 바늘, 방패, 거북이·부엉이(한 번 맞아도 내림).
- 3분이 지나면 무승부, 1분 남으면 "Hurry Up!".
- 캐릭터 26명(다오, 디지니, 배찌, 마리드, 에띠, 모스, 우니, 케피, 수, 후우, 레이, 루시와 럭셔리·슈퍼 캐릭터)마다
  물풍선·물줄기·속도의 시작값과 최대값이 다릅니다.

## 원본 에셋

`npm run ca:assets`가 `taebo-games-crazyarcade-assets`의 `pc/PatchData`(`.idx` 목차 + `.idd` 데이터)를 읽어
`assets/ca/`에 PNG 시트·JSON·JPEG·MP3로 바꿉니다(`tools/ca-formats.mjs` 맨 위에 포맷 설명). `assets/`는 git에 올리지 않습니다.

- 캐릭터는 레이어 3장(A/B/C) × 2종(팀 색으로 바뀌는 `LayerAdjust`, 그대로인 `LayerStatic`)을 겹쳐 그립니다.
  빨간색 부분을 팀 색 색상으로 돌려 8팀 색을 만듭니다.
- 맵 데이터와 아이템 표는 원본에서 암호화되어 있어, 맵은 공식 미리보기 이미지에서 칸마다 복원했습니다(`tools/maps/`).
  숨은 아이템 배치 규칙은 원본을 못 읽어 확률로 정합니다. 캐릭터 능력치도 알려진 값으로 넣었습니다.

## 아직 없는 것

상점, 꾸미기(아바타), 펫, 몬스터 모드 같은 부가 콘텐츠. 에셋(아바타 파츠 7,800개, 상점 화면 등)은 원본에 다 있어서
순서대로 붙일 예정입니다.
